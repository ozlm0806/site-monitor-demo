# 工地環境安全即時監控系統｜線上展示站

**展示網址：** <https://ozlm0806.github.io/site-monitor-demo/>　｜　試用後台：<https://ozlm0806.github.io/site-monitor-demo/admin.html>

以虛構的「示範營造股份有限公司」與兩處臺東示範工地（豐年機場、臺東地方法院）呈現即時資料，供營造廠了解客製化建置後的成果。

- 後台試用帳號 `demo` / `demo1234`：可新增工地、調整門檻、預覽效果，變更只保存在試用者的瀏覽器，無法發佈。
- 管理者帳號 `admin` 才能發佈修改。
- 程式與開楠營造版相同，另加「展示版」橫幅、試用帳號與社群分享預覽圖（og-image.png）；瀏覽器儲存鍵名使用 `klwsdemo_` 前綴，避免與同網域的正式站互相干擾。

數值會隨時更新，研判門檻為一般參考值，停工與復工仍依現場實測、契約規定與監造指示。
